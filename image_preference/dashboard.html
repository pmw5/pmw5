Setup notes (if you hit permission errors)
This dashboard reads all images and all votes, so your RLS policies must allow:
  • Admins to SELECT from images (not just active images).
  • Admins to SELECT from votes.
If you only added a “public read active images” policy, also add: 
create policy "admins read all images"
on public.images for select
to authenticated
using (exists (select 1 from public.admins a where a.user_id = auth.uid()));
